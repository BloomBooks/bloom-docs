Image format

Images exist in various file formats (file types), such as JPEG (.jpg), PNG (.png), TIFF (.tif), or Bitmap (.bmp).

Consider the following:

  • If you choose a *.bmp image, Bloom will convert that image to *.jpg. This reduces the size of the file.

  • *.jpg format is only suitable for photographs, but not for line art.

  • The images from Art of Reading are typically *.png.

  • Scanned images usually become *.tiff or *.png files. If you have a choice, use *.png.

Important

  • If you convert a line art image to *.jpg, it will cause errors that you can see as a noticeable reduction in quality.

If you convert that image again to another format, those errors will follow into the new format. This is true even if the new format is the format that was originally used.

Image conversion happens if you use Save As and choose a different format for the image file.

  • Hold your mouse pointer over an image in Bloom to see a pop-up box. This box contains the information about that image.

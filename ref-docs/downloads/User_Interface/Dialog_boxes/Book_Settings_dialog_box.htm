Book and Page Settings dialog box

To open the Book Settings dialog box, click Book Settings () in the Edit tab toolbar. The dialog box has six areas.

Theme & Layout

Page Themes are a bundle of margins, borders, and other page settings. For more information, see: Page Themes Catalog on the Internet. Some themes you can choose allow you to choose locations for page numbers, and other advanced layout options. You might want to get more help.

Cover

Here are options you can select () or clear () for the front cover page:

  • Show Title in: Select the language or languages you want to use for the book title.

  • Show Language name: Select if you want those languages names to appear near the bottom of the front cover.

  • Show Topic: Select if you want to the topic to appear on the front cover.

  • Show Credits: Clear this check box if you want to hide the credits and allow the front cover image to fill that space.

  • Background Color: Click the color control and then use the dialog box to choose the desired color.

Languages

  • Select () the languages you want to show in normal text boxes. Clear () any other languages.

Print Publishing

This option requires a high subscription tier. You might want to get more help.

BloomPUB

For books you will publish as a BloomPUB, you can use dialog box to set the maximum size of the images. The size you set here is used for the display of the book on BloomLibrary.org. 

Bloom resizes images to the maximum size you set with these goals in mind:

  • Images should be easy to view over a poor internet connection.

  • Images should use less space on phones.

  • There should be no noticeable loss of quality.

To set the maximum size, simply click and slide the Resolution slider
(). 

  • Sizes are stated with words: Small, HD, Full HD or 4K. 

  • They are also stated by pixels: 600x600, 1280x720, 1920x1080 or 3840x2160.

The aspect ratio of your images are not changed.

For example, if you had a rectangular image and you set it to 600x600, the maximum dimension in either direction will be 600 pixels. It will not become square.

Fonts

The Fonts tab has a table of all the fonts that are used in the current book.

  • The First Page column lists the first page that uses each if the fonts and is a link that open that page in the Edit tab.

  • If you used a font that cannot be published or is wrong for another reason, you will see a warning.

Configure the style to use a different font for each warning.

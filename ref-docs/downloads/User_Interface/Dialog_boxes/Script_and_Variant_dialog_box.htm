Script and Variant dialog box

  1. In the Lookup Language Code or Create New Bloom Collection dialog box,
    do these steps:

    • Select () Show regional dialects to see any regional dialects.

    • Click the language or a regional dialect of that language.

    • Click the Script and Variant link.

This Script and Variant dialog box opens.

If you clicked a dialect, the region information appears in the Region box.

Important: Before you continue, click the Read about Language identifiers on the web link to learn more about when and why you should use script, region or variant identifiers.

Then, do any of these steps:

  1. In the Abbreviation box, edit the abbreviation to distinguish this language.

  2. In the Script box, choose a script.

    • To remove a script, click the blank space at the top of the drop-down list.

  3. In the Region box, choose a region where the language is spoken.

    • To remove a region, click the blank space at the top of the drop-down list.

  1. In the Variant box, type the name of the variant.

    • To remove a variant, select and delete whatever is in the Variant box.

  1. Click OK.

The Script and Variant dialog box closes. The Lookup Language Code or Create New Bloom Collection dialog box remains open.

Notice that your choices appear next to the Script and Variant link.

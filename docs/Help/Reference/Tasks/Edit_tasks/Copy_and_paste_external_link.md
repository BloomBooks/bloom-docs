## Copy and paste an external link

An external link (hyperlink) allows readers to navigate from a page in a book to a website.

### Prerequisites

-   You need to have a copy of the desired url on your clipboard.

### Do these steps

1.  Click the ![](/ref-docs-assets/images/User_Interface/Tabs/EditTab.png)**Edit** [tab](../../User_Interface/Tabs/Tabs_overview.md).
    
2.  In the **Pages** pane, click the page that you want to have a hyperlink.
    
3.  Select the desired text (number, word or phrase).
    
    The direct formatting [panel](../Basic_tasks/Formatting_text/Apply_direct_formatting.md) appears.
    

4.  Click ![](/ref-docs-assets/images/Tasks/Basic_tasks/Formatting_text/PasteHyperlink.png) (Set Up Hyperlink).
    
5.  In the **Choose Link Target** dialog box, click ![](/ref-docs-assets/images/Tasks/Edit_tasks/PasteFromClipboard.png) (Paste from clipboard) to paste the url into the **URL** box. 
    
6.  Click **OK**.
    

The text you selected becomes underlined and changes color to show it has the hyperlink.

#### Note

-   You can edit text after you paste the hyperlink.
    
-   If you make mistake or choose to remove the hyperlink from the text, delete the number, word or phrase.
    

Then, type that text again.

## Script and Variant dialog box

1.  In the **Lookup Language Code** or ![](/ref-docs-assets/images/BloomIcon_red.gif) **Create New Bloom Collection** dialog box,  
    do these steps:
    
    -   Select (![](/ref-docs-assets/images/SelectedCheckBox.png)) **Show regional dialects** to see any regional dialects.
        
    -   Click the language or a regional dialect of that language.
        
    -   Click the **Script and Variant** link.
        

This **Script and Variant** dialog box opens.

If you clicked a dialect, the region information appears in the **Region** box.

![](/ref-docs-assets/images/Important_Icon.gif) **Important:** _Before_ you continue, click the **Read about Language identifiers on the web** link to learn more about when and why you should use script, region or variant identifiers.

Then, do any of these steps:

2.  In the **Abbreviation** box, edit the abbreviation to distinguish this language.
    
3.  In the **Script** box, choose a script.
    
    -   To remove a script, click the blank space at the top of the drop-down list.
        
4.  In the **Region** box, choose a region where the language is spoken.
    
    -   To remove a region, click the blank space at the top of the drop-down list.
        

5.  In the **Variant** box, type the name of the variant.
    
    -   To remove a variant, select and delete whatever is in the **Variant** box.
        

6.  Click **OK**.
    

The **Script and Variant** dialog box closes. The **Lookup Language Code** or ![](/ref-docs-assets/images/BloomIcon_red.gif) **Create New Bloom Collection** dialog box remains open.

Notice that your choices appear next to the **Script and Variant** link.

## About these Reference Docs

This section is Bloom's complete **reference manual** — the same material that ships inside Bloom as its offline Help file. Because it mirrors the in-app Help, a few of the pages here (the "overview" and "getting started" topics) are written as though this were your entry point into Bloom.

If you are new to Bloom or want step-by-step guidance, start with the [main Bloom documentation](/) instead. Use this Reference section to look up the details of a specific dialog box, tool, or menu, or to read about a particular [task](./Tasks/Tasks_overview.md) or [concept](./Concepts/Concepts_overview.md).
